# 花 Buff 观察与音乐提醒

经验观察器在记录运行期间观察游戏右上方的神圣祈祷图标。在主面板大号每分经验右侧显示与游戏相同的方形图标、从下往上推进的暗色倒计时遮罩及黄色剩余秒数；分钟数用白字，从未识别到/暂停/关闭时图标置灰。已识别后被喇叭遮挡仍保留图标、计时和遮罩动画，标注“预计”；到期未取得新画面则标注“待确认”。默认提前15秒播放一段1.6秒的四音提示音乐，每轮一次。识别设置可关闭监测、单独关闭音乐、调整提前量（5—30秒）和试听；点击花图标也可进入设置。没有语音播报。

只读取可见画面，不读取游戏内存，不发送游戏按键。图标模板来自国服官方三转技能卡，出处嵌入 `assets/holy-symbol-anchor.png`。只在游戏顶部区域匹配该图标，支持图标位置变化和多个尺寸；倒计时使用独立、限线程的本地 OCR。没有联网识别、模型唤醒或定时会话。

精确计时需要连续两帧一致的黄色秒数，不能只凭图标出现就假定新获得120秒。取得可靠秒数后保存单调时钟到期点；喇叭等游戏内遮挡导致图标/数字暂时不可读时，继续按该到期点计时，图标下方明确显示“预计”，到阈值同样播放音乐。重新读到实际时间时校准，确认时间增加后重置为新一轮。隐藏期间是否补过花无法从屏幕得知，因此预计提醒不代表确认 Buff 即将消失。

白色分钟数不能产生精确到期点；尚未见到秒数时，优先结合图标暗色边界估计剩余时间，缺少边界数据时采用该分钟区间中值，始终标注“预计”。暗色比例和分钟阶段初估使用满花120秒参考，不将它当作一次实测施放；未满花时初估会有偏差，读到可靠秒数立即校准。连续确认的分钟数若与此前即将到期的秒数冲突，可确认刷新并替换旧预测。从启动起完全未识别到花图标及时间时保持等待，不编造周期。游戏最小化、外部窗口挡住识别区域、捕获失败或过期帧不产生新的提醒；停止记录和关闭功能也会停止提醒。失去图标本身不会清除同轮提醒去重。

识别以约0.3秒为最小间隔，由独立后台线程执行；实际间隔也受界面轮询和识别耗时影响，最多一个识别任务和一个结果。支持图标从下往上的变暗遮罩。提示音乐使用 Windows 异步音频播放，不排队叠播，真正的到期提醒优先于试听；失败在界面显示。无需中文语音包或额外进程。配置保存在与观察器设置相同目录的 `flower-buff.json`，不进入历史数据库。

当前限制：只覆盖原版图标及右上 Buff 栏，不能读取被遮住的像素，也无法识别全程隐藏的刷新。预计提醒依赖此前可靠时间读数或明确标注的分钟估计，只是补花参考。自定义UI、其他客户端版本和非黄色秒数需要额外样本验证。技能百分比、等级差及经验分配规则不参与本功能。

验证入口：`python -m unittest test_flower_buff test_primary_rate_ui test_app_resume`。状态机测试覆盖单帧误读、连续读数、重复播报、刷新、遮挡、暂停后的旧任务、过期结果和静音。图像测试覆盖图标位置/尺寸变化与无图标负例；合成图片不能代替实机闭环。

音频 `assets/flower-reminder.wav` 为本地合成的原创 C5/E5/G5/C6 四音提示，44100Hz、16bit、单声道；无第三方录音或外部音频来源。

2026-10-17 本轮已从真实花图标读取1分钟和44秒，44秒暗色遮罩匹配分0.933；150秒静音探针观察到两轮独立提醒事件，包含遮挡预计与随后重新读秒。已安装版也产生一次音乐提醒事件，音频输出无错误。此前其他 Buff 的黄色38秒只用于验证读秒路径。分钟阶段遮挡续计时和阴影动画另有回归验证；当前已观察的样本不代表所有等级、窗口布局和遮挡组合均已实测。
