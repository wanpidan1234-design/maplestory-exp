# 冒险岛 · 网页经验观察器

[打开网页版](https://wanpidan1234-design.github.io/maplestory-exp/) · [下载本机服务源码 ZIP](https://github.com/wanpidan1234-design/maplestory-exp/archive/refs/heads/codex/web-companion.zip)

网页通过本机服务使用现有经验统计、屏幕识别、SQLite 历史与桌面悬浮能力。GitHub Pages 只托管静态网页，不能直接读取游戏画面或运行 Python。所有玩家数据、截图、连接码、日志和个人知识库保存在本机，不随网站发布。

## 启动

1. 游戏电脑使用 Windows 10/11，安装 Python 3.10 或更新版本，并允许 `python` 在命令行运行。已有项目虚拟环境可直接复用。
2. 解压上述源码 ZIP，双击 `start-web.cmd`。首次运行会建立虚拟环境并安装 `requirements.txt`，请等待完成。
3. 服务启动后自动打开已配对的 GitHub Pages 网页。浏览器询问“本地网络访问”时允许；推荐使用当前桌面版 Chrome 或 Edge。
4. 进入冒险岛国服怀旧服，保持游戏窗口与经验栏可见。网页和悬浮球共享同一个统计实例。

已有旧版独立程序正在运行时，先从悬浮球菜单正常退出，再运行 `start-web.cmd`。启动入口会检查单实例锁，避免重复计账；如果已经运行支持网页的实例，则只打开其网页。

如果浏览器禁止 HTTPS 页面连接本机服务，可运行：

```powershell
.\.venv\Scripts\pythonw.exe web_start.py
```

它打开 `http://127.0.0.1:17321/` 的同一套界面，所有功能相同。配对地址包含临时连接码，启动器自动传给网页并立即从浏览器地址栏移除；每次服务重启会更换连接码。不要把带连接码的地址发给他人。

| 历史回看 | 北京时间日期与记录筛选、所有分均口径、全天分钟收益、采样分页、CSV 导出 |
| 战斗明细 | 本次与当日伤害/血蓝变化、怪物击杀汇总、事件查询、完整战斗与击杀 CSV |
| 三转答题 | 游戏截图框选、持续本地 OCR、保守答案匹配、手动查题、本机已有速查 PDF 下载 |
| 攻略资料 | 本地 Markdown 资料阅读、索引知识检索、来源/版本/置信评分/限制；个人库不存在时明确显示空状态 |
| 识别与设置 | 自动定位、经验栏框选、升级经验、悬浮球透明度、花 Buff 音乐和提前时间、升级核验、跳过差值、新建记录、诊断与评审状态 |
| 桌面联动 | 悬浮球、夜航统计面板、历史/战斗/多尺度/识别独立窗口、原版升级动画与后台评审详情 |

网页“置顶小窗”使用浏览器 Document Picture-in-Picture，是否支持取决于浏览器。原有透明悬浮球由本机窗口提供，仍可使用。关闭网页不会关闭本机采集，结束采集使用“暂停记录”或从悬浮球正常退出。

框选时点击截图按钮后有 3 秒切回游戏，让游戏完全可见；完成后返回网页拖动选区，或使用 X/Y/宽/高输入。移动游戏、改变尺寸或缩放后应重新截图。答题识别不推断选项序号，低置信或冲突结果不会显示成确定答案。

战斗识别仍然是单人可见画面估计，网页化不增加识别准确率。保留原有采样中断、下界、升级确认和断点接续规则。各图表不补造无观察期间的记录。

## 数据与运行

- `web_start.py` 默认接续 `%LOCALAPPDATA%\MapleExpTracker\data\history.sqlite3`，可通过 `MAPLE_EXP_DATA_DIR` 指定已有数据目录。
- 源码 `orb.py` 的默认数据库行为不变。也可直接 `pythonw orb.py --web`，但应先确认它选择的数据库。
- 仅一个桌面引擎写数据库；HTTP 线程使用独立只读连接。所有修改通过有界队列交回引擎所有者线程，排队超时后不再执行。
- 监听范围只有 `127.0.0.1:17321`。接口检查 Host、来源白名单、每次启动生成的随机连接码；不提供任意文件读取、命令执行或模型唤醒接口。
- 历史 CSV 保留存储的算法/窗口/缺口字段，并增加北京时间列。本次记录导出跨越午夜也会导出完整会话。
- 网页状态查询是本地数据显示，不调用模型。已有后台评审仍遵循项目的启动事件与维护重启规则；独立发行环境使用 `--no-startup-review`。
- 手机版布局可正常阅读，但当前连接指向当前设备的回环地址。手机不能直接访问电脑采集服务；跨设备配对需要另行增加经过认证的访问通道。

## 发布与验证

`web/` 是无需构建的静态目录，只发布 HTML、CSS、JavaScript、图标与 `.nojekyll`。源码保存在 `codex/web-companion` 分支，静态页面发布到 `gh-pages`；不从项目根目录打包网站。

```powershell
.\.venv\Scripts\python.exe -m unittest test_web_bridge test_app_resume test_rate_app test_startup_review_app
node --check web/app.js
```

真实浏览器测试应覆盖已连接、未连接、空历史、分页、导出、设置保存、答题与知识查询、桌面/手机尺寸、GitHub Pages 到本机的跨源访问。无游戏画面时，不能把接口或合成数据测试宣称为实机 OCR 验收。
