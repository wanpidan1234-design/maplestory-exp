# 三转答题助手

## Windows 独立版 1.0.0

[下载 ZIP](https://github.com/wanpidan1234-design/maplestory-exp/releases/download/quiz-v1.0.0/MapleQuizHelper-1.0.0-windows-x64.zip) · [发布说明及校验文件](https://github.com/wanpidan1234-design/maplestory-exp/releases/tag/quiz-v1.0.0)

解压后运行 `MapleQuizHelper.exe`，保留同目录 `_internal` 文件夹。适用于 Windows 10/11 x64，无需安装 Python；内置题库和离线 OCR 模型。此工具独立启动，使用方法与下方源码版相同。

这是独立于经验统计的屏幕辅助工具。打开 `start-quiz.cmd`，在游戏中进入答题对话，然后点击 **框选题目区域**，拖动选取完整题干与全部选项。框选后开始本地 OCR，答案显示在置顶小窗中。把助手放在答题区域之外；Esc 可取消框选。

显示的是**答案文字**，不推断选项序号。手动查题支持关键词搜索，选择题目后会暂停自动识别。点“开始识别”恢复。关闭助手即停止截图；不保存屏幕图片，不修改经验数据库，不调用模型、不发送游戏按键或点击。

窗口底部的 **打开题库 PDF** 可打开已有的参考文件；未找到桌面的默认文件时会让你自行选择。独立安装包不包含个人桌面 PDF，此按钮不影响内置题库和 OCR 功能。

## 题库与边界

- 来源：[国服怀旧服小册子三转题库](https://mxdc.dvg.cn/tools/third-job-quiz/)，获取日期 2026-10-15。
- 本地文件：`assets/third-job-quiz-cn.json`。39 道社区参考题；原页面 44 条，排除 1 条重复、1 条历史选项版本和 3 条非题干提醒。不是官方完整题库保证，尚未逐题在当前客户端验证。
- 保留每条题目与来源，不使用来源页面的选项序号。完整匹配显示答案；题干扩写、同义问法或 OCR 错字会尝试近似匹配，以黄色“参考：答案”显示对应题干。
- 正反问法、数字改变、相近题目歧义、低 OCR 置信度，以及敏感题未识别到答案选项时，仍尽可能给出参考答案，但不会标为完整匹配。分数接近时同时列出最多三条不同答案的候选及题干，需自行核对。相似分数不是正确概率；无相关文字或只有选项时仍等待完整题目。
- 框选范围限定于标题为“冒险岛怀旧服”的游戏客户区，跟随游戏移动；窗口大小、缩放或实例变化后需重新框选。
- 最小化、遮挡、画面变化、捕获失败、超时及暂停时清除自动答案。识别后再次检查像素，丢弃处理中已变化的画面。按约 0.8 秒间隔本地采集，识别耗时受电脑与题目区域大小影响；任何变化到界面清除之间仍有采集延迟。
- 请框紧静态对话区域，避免把会动的地图、光标或人物包含在范围内。过大的动态区域可能一直显示“等待题目稳定”。
- OCR 完全离线，依赖项目已有的 RapidOCR 1.2.3、ONNX Runtime、MSS、OpenCV 与 Tkinter。识别线程独立，检测/识别线程池各限制为 1；相同像素复用结果。

## 验证

运行 `.venv\Scripts\python.exe -m unittest discover -s tests -p "test_quiz*.py" -v`。

回归包含全题库匹配、错字/否定词/数字、歧义、屏幕边界、遮挡、异步状态与真实 OCR 合成图片测试。独立版另有内置模型、39题数据、手动查题、窗口关闭和不创建历史数据库的打包自检。合成题图通过不等于实机题目准确率已验证；正式使用仍应核对游戏原题与选项。

答题器版本使用 `quiz-v*` 标签单独发布；经验观察器的 EXE 不会自动打开答题器。
